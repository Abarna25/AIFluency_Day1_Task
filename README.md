## Project Overview

This assignment demonstrates the differences between three approaches for solving the same private-data problem:

1. **Plain Chatbot (LLM Only)**
2. **Rule-Based Workflow**
3. **AI Agent (LLM + Tools + Loop)**

The chosen scenario is a **Student Marks Management System**, where student marks are treated as private data and are not directly available to a public language model.

## Contents

### chatbot.py

Implements a plain chatbot using an LLM without access to private student data.

### workflow.py

Implements a rule-based workflow using predefined conditions and business rules.

### tools.py

Contains tools that provide access to private student marks data.

### agent.py

Implements an AI agent that combines an LLM with tools to answer user queries.

### analysis.md

Contains the complete written analysis required for the assignment, including:

* Explanation of each approach
* Comparison table
* Suitability analysis
* Conclusion

### Output Folder

Contains the outputs generated by all three systems when executed on the selected scenario.

## Scenario

The project uses a Student Marks Management System containing private student marks data.

Example records:

| Student | Mark |
| ------- | ---- |
| Abarna  | 92   |
| Priya   | 85   |
| Kavin   | 78   |
| Rahul   | 88   |

Example questions:

* What is Abarna's mark?
* Who scored the highest?
* What is the average mark?
* Which students scored above 85?

---

## Objective

The objective of this assignment is to understand how different AI system designs handle the same task and to demonstrate why AI agents are often more capable when private-data access, tool usage, and multi-step reasoning are required.
